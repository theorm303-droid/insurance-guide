보험 보장 가이드 — 홈페이지·전자책 관리 안내 (2026.10)
====================================================

[폴더 구성]
  index.html, ch01~ch41.html, cat-*.html 등   홈페이지 (이 폴더째 호스팅에 올리면 됨)
  assets\                                     디자인(css), 스크립트(js), 프로필 사진, QR코드
  전자책\한권으로끝내는_보험보장가이드.pdf    전자책 PDF
  전자책\한권으로끝내는_보험보장가이드.html   전자책 한 파일 HTML (사진·QR 포함)
  전자책\src\                                 원고 (글을 고칠 때는 여기 파일을 수정)
  build_site.py                               홈페이지 다시 만들기
  전자책\build.py                             전자책 PDF·HTML 다시 만들기
  _artifact_home.html                         claude.ai 미리보기 게시용 (호스팅에는 올리지 않아도 됨)

[글을 고친 뒤 다시 만들기]
  1) 전자책\src\ 안의 원고 수정
  2) 전자책 폴더에서:   python build.py        → PDF·HTML 갱신
  3) 이 폴더에서:       python build_site.py   → 홈페이지 전체 갱신

[연락처·카톡·등록번호 바꾸기]
  build_site.py 맨 위 "상담·연락처 설정" 부분만 수정 후 python build_site.py
  (전자책의 연락처는 전자책\src\00_front.html 과 12_appendix.html 에 있음)

[사진 바꾸기]
  assets\profile-portrait.jpg 와 전자책\src\profile-portrait.jpg 를 같은 이름의 새 사진으로 교체
